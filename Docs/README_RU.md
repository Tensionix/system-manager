# Audion System Manager

[English README](README_EN.md) · [User Guide](USER_GUIDE_EN.md) | [Русский README](README_RU.md) · [Руководство](USER_GUIDE_RU.md)

Одно окно для рабочего окружения разработчика на Windows: **PowerShell 7**, **Windows Terminal**, **Python 3.12**, **VS Code**, **Git** с **GitHub CLI** и агенты в консоли **Claude Code**, **Codex**, **Grok Build**. Каждую программу можно поставить в систему или развернуть портативной папкой — со всеми опциями, которых не даёт менеджер пакетов, и с настройками Audion. Кнопками, без чёрного окна консоли и без ключей командной строки.

## Зачем это сделано

Установка через менеджер пакетов ставит программу, но не настраивает её. Мастер установки предлагает опции, о которых через полгода не вспомнишь. А настройки после установки собираются заново на каждой машине. Программа берёт всё это на себя.

| Раздел | В систему | Портативно |
|---|---|---|
| POWERSHELL 7 | MSI для всей машины со всеми опциями: меню Проводника, PATH, журнал событий, обновления через Microsoft Update; профиль Audion | zip релиза в папку |
| TERMINAL | Windows Terminal из Магазина (или через WinGet) и настройки Audion во всех найденных терминалах; терминал по умолчанию; шрифт Cascadia Nerd Font | zip релиза в папку, настройки рядом |
| PYTHON 3.12 | установщик python.org для всех, в свою папку, путь в начале PATH, лаунчер py, без заглушек Магазина; pip у всех Python | полный архив python.org с pip |
| VS CODE | установщик на машину или в профиль со всеми галочками мастера, настройки, клавиши и сниппеты, расширения по спискам | архив в папку с папкой data, обновление без потери настроек |
| GIT | Git for Windows со всеми галочками мастера; GitHub CLI со входом через браузер; настройки Git Audion, личные не трогаются | PortableGit в папку, GitHub CLI рядом |

Раздел **AI CLI** ставит и обновляет Claude Code, Codex и Grok Build установщиками их авторов, а вход и выход по подписке (OAuth в браузере) — кнопкой у каждого.

Права администратора спрашиваются только для установки на всю машину — окном UAC установщика. Скачанное лежит в `Download`, портативные сборки — в `Portable`: **папку можно унести на другую машину целиком**.

## Запуск

`Start.exe`. Подробно — в [руководстве](USER_GUIDE_RU.md).
